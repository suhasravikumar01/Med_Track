# 💊 Med_Track
### Medicine Reminder and Management System

**Med_Track** is a simple C-based application designed to help users organize and manage their daily medication schedules.

The system allows users to add medicines, categorize them based on health conditions such as Thyroid, Diabetes, and Blood Pressure, specify dosage frequency, and manage their medication routines.

## 🎯 Objective

To simplify daily medicine management by providing an organized way to maintain medicine details and track prescribed medication schedules.

## ✨ Key Features

- **Add Medicine:** Enter medicine names and related details.
- **Health Condition Categories:** Organize medicines according to health conditions.
- **Dosage Frequency:** Specify how many times a medicine needs to be taken per day.
- **Medicine Timings:** Set scheduled timings for medication.
- **View Medicines:** Display stored medicine details.
- **Medication Tracking:** Record medicines that have been taken.

## 🚀 Getting Started

### Prerequisites

- GCC Compiler
- Visual Studio Code
- C/C++ Extension for VS Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/suhasravikumar01/Med_Track.git
```

**2. Navigate to the project folder**

```bash
cd Med_Track
```

**3. Compile the C program**

```bash
gcc main.c -o med_track
```

**4. Execute the program**

For Windows:

```bash
.\med_track.exe
```

For Linux/macOS:

```bash
./med_track
```
